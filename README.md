# Online Quiz System

## 📌 Project Description

The Online Quiz System is a web-based quiz application developed using HTML, CSS, and JavaScript. It allows users to attend quiz questions, select answers, and view their results.

## 🚀 Features

- User-friendly quiz interface
- Multiple-choice questions
- Answer selection
- Automatic result calculation
- Displays quiz results
- Simple and responsive design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 📂 Project Files

- `index.html` – Main/home page
- `quiz.html` – Quiz page
- `result.html` – Result page
- `style.css` – Styling and design
- `script.js` – Quiz functionality and logic

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start the quiz and answer the questions.
5. View your result after completing the quiz.

## 🎯 Objective

The main objective of this project is to create a simple and interactive online quiz system using basic web development technologies.
